# Procédure de commande annulée

Version : 1.0  
Statut : approuvée

Utiliser cette procédure lorsqu'une commande est `cancelled`.

1. Confirmer le statut réel de la commande.
2. Informer le client que la commande est annulée.
3. Ne pas annoncer une expédition ou une livraison pour cette commande.
4. Si le client conteste l'annulation, escalader à un opérateur.
5. Tout remboursement éventuel suit séparément `refund_policy.md`.

Le statut d'une commande annulée ne doit pas être modifié automatiquement par l'agent.
